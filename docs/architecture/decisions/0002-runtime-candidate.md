# ADR-0002: Paperclip and OpenClaw candidate

Status: proposed, not accepted as the final architecture.

Rationale: a relevant organization cockpit paired with an existing conversational runtime.
Acceptance requires QUAL-01 through QUAL-06, with integration effort and maintenance assessed.
Revise or reject if substantial work bypasses the cockpit, costs cannot be attributed, or recovery remains uncontrolled.
Alternatives: Sim for integrated workflows; Mastra when building a custom cockpit is justified.
