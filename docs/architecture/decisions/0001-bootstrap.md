# ADR-0001: Project foundation

Status: accepted for initialization under the user's delegation, 2026-09-14.

Use Git for code, configuration, instructions and source documents. Install BMAD stable 6.12.0 for Codex.
Track official installed files without custom modifications. Keep project-specific configuration separate.
All repository content and commit messages are English; conversation may be French.
Product implementation and deployment follow architecture qualification.

Consequences: reproducible handoff and reviewable changes. BMAD adds many files; upgrades require a dedicated reviewed change.
