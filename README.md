## Start here

1. Read `docs/START-HERE.md` and `AGENTS.md`.
2. Connect this repository to Codex cloud; use `bash scripts/cloud-setup.sh` for setup.
3. Read `_bmad-output/planning-artifacts/product-brief.md` and `prd.md`.
4. Invoke `bmad-help` in a new project session to resume the installed workflow.
5. Run `python3 scripts/check_project.py` to validate the documentation baseline.

Planning sources live in `_bmad-output/planning-artifacts`; decisions, contracts and procedures live in `docs/`.
Official installed skills are tracked in `.agents/skills`, with their runtime in `_bmad`.
Product dependencies will be selected after technical qualification.
