# Workstead product brief

Status: DRAFT. Conversation-derived input; not a completed or approved BMAD workflow.

## Purpose

Build a frugal, self-hosted, open platform for configuring and supervising hybrid organizations.
Humans and AI agents collaborate on missions, use familiar tools and produce reviewable digital deliverables.

## Initial user

Emmanuel is the developer and organization operator. This is a personal exploratory project.
He needs to inspect work, intervene, and change providers without rebuilding business processes.

## Demonstration

A digital studio includes a production lead, writer, media creator, developer and human owner.
It receives a brief, proposes a plan, reviews a script, produces a video and a small application,
handles requested changes and records human acceptance.

## Established constraints

Reuse existing software; minimize custom code and maintenance; use open-source components and portable interfaces.
Start on one server. Support replaceable conversations, ticketing, storage, model gateways and media providers.
Prioritize visual supervision. Iterate documents before producing a final PDF.
Keep all repository artifacts in English.

## Success

A completed mission has an observable result, accountable owner, review decision and attributable cost.
The same process works with a second channel and external storage through configuration and mappings.
Recovery reconciles existing jobs before submitting another paid operation.

## Pilot exclusions

Real financial portfolio management, unlimited autonomy, fifty concurrent agents,
federation across untrusted organizations and a universal workflow engine.
